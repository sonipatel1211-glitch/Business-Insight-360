# Business-Insight-360
#  Consumer Goods Analytics

Consumer Goods Analytics dashboard for tracking business performance and generating actionable insights.
##  Project Overview

Business-Insight-360 is a Power BI dashboard for AtliQ Hardware that provides insights across Sales, Finance , Supply Chain, Marketing, and Executive views to help understand business performance and support data-driven decisions.

##  Tools & Skills

- Excel
- Power BI
- Power Query
- DAX
- Data Cleaning
- Data Visualization
- Dax Studio 

##  Key Insights

- Analyzed Sales & Revenue performance and trends.
- Evaluated Finance metrics, profitability, and margins.
- Monitored Supply Chain performance and key KPIs.
- Analyzed Marketing performance and customer insights.
- Created an Executive View for quick business performance tracking.
